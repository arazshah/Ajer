# آجر؛ مالک و مستأجر

آجر یک SaaS فارسی و راست‌به‌چپ برای مدیریت حرفه‌ای دفاتر و مشاوران املاک سراسر ایران است. هر دفتر فضای مستقل خود را دارد و فایل‌ها، مالکان، متقاضیان، پیگیری‌ها، بازدیدها، معاملات و کاربران آن از تمام دفاتر دیگر جدا می‌مانند.

## امکانات اصلی

- ثبت‌نام عمومی مدیر دفتر و دوره آزمایشی ۳۰روزه
- کاربران نامحدود برای مشاوران و بازاریاب‌های همان دفتر
- مدیریت نقشه‌محور فایل، مالک، متقاضی، بازدید و معامله
- حسابداری یکپارچه دفتر شامل صندوق، بانک، تنخواه، درآمد و هزینه، چک، مطالبات، حقوق، پورسانت و سود و زیان
- گزارش مدیریتی قیف فروش، عملکرد پرسنل، منابع جذب، مناطق پربازده و فایل‌های راکد
- پرونده حقوقی قرارداد با نسخه‌بندی، طرفین، شهود، تعهدات، چک‌لیست مدارک، ثبت کاتب، پیوست و چاپ A4
- تاریخ شمسی سراسری در نمایش و ورود اطلاعات با منطقه زمانی ایران
- تطبیق نیاز مشتری با فایل و جست‌وجوی زبان طبیعی با AI
- پلن‌های ۱، ۳، ۶ و ۱۲ماهه با افزونه اختیاری AI
- درخواست تمدید دستی با فیش خصوصی، تأیید سوپرادمین و زرین‌پال اختیاری
- پایش رخداد، timeout و retry کنترل‌شده برای AI، پیامک و پرداخت در پنل سوپرادمین
- پنل خصوصی سوپرادمین برای مدیریت دفاتر، درآمد و قیمت پلن‌ها
- نشست دیتابیسی قابل‌ابطال، محدودسازی ورود، مرکز رویدادهای امنیتی و هدرهای سخت‌گیرانه مرورگر
- health/readiness واقعی، backup زمان‌بندی‌شده با checksum و ذخیره‌سازی خصوصی local یا S3-compatible
- راهنمای داخلی برای تمام قسمت‌های محصول
- PostgreSQL، Prisma، Next.js App Router و Docker Compose آماده Coolify

## توسعه محلی

برای اجرای PostgreSQL توسعه با Docker و راه‌اندازی برنامه:

```bash
cp .env.example .env
npm ci
npm run db:dev:up
npm run db:migrate
npm run db:seed
npm run dev
```

این Compose فقط در محیط توسعه، PostgreSQL را روی پورت `55432` میزبان در دسترس می‌گذارد. برای متوقف‌کردن آن `npm run db:dev:stop` را اجرا کنید. اگر PostgreSQL را جداگانه اجرا می‌کنید، کافی است `DATABASE_URL` را متناسب با آن تغییر دهید. seed داده‌های ساختگی ایجاد می‌کند؛ آن را روی دیتابیس واقعی اجرا نکنید.

حساب‌های نمایشی پس از seed:

- `admin@ajer.ir` / `Ajer123!`
- `agent@ajer.ir` / `Ajer123!`

## متغیرهای سرویس

- `APP_URL`: نشانی عمومی و HTTPS برنامه برای callback پرداخت
- `SESSION_SECRET`: رشته تصادفی حداقل ۳۲ نویسه
- `AI_API_KEY`, `AI_BASE_URL`, `AI_MODEL`: سرویس سازگار با OpenAI
- `ZARINPAL_MERCHANT_ID`, `ZARINPAL_SANDBOX`: درگاه پرداخت
- `SMSIR_API_KEY`, `SMSIR_WELCOME_TEMPLATE_ID`, `SMSIR_PAYMENT_TEMPLATE_ID`: پیامک قالبی
- `SUPER_ADMIN_EMAIL`, `SUPER_ADMIN_PASSWORD`: تنها حساب مدیریت کل؛ این حساب فرم ثبت‌نام ندارد
- `SETTINGS_ENCRYPTION_KEY`: کلید ثابت و حداقل ۳۲ نویسه‌ای برای رمزگذاری کلیدهای سرویس در دیتابیس
- `NEXT_SERVER_ACTIONS_ENCRYPTION_KEY`: کلید base64 مستقل برای پایداری امن Server Actionها میان استقرارها
- `STORAGE_DRIVER` و متغیرهای `S3_*`: انتخاب ذخیره‌سازی خصوصی محلی یا S3-compatible
- `HEALTHCHECK_SECRET` و متغیرهای `BACKUP_*`: پایش readiness و سیاست نگهداری نسخه پشتیبان

کلیدهای سرویس فاقد پیشوند `NEXT_PUBLIC_` هستند و فقط در سرور خوانده می‌شوند.
پس از ورود سوپرادمین، AI، پیامک، روش تمدید دستی/آنلاین، اطلاعات بانکی، زرین‌پال، ثبت‌نام، دوره آزمایشی و اطلاعات پشتیبانی از داخل پنل قابل مدیریت‌اند و تغییر آن‌ها به استقرار مجدد نیاز ندارد. حالت پیش‌فرض پرداخت «بررسی دستی» است.

## آزمون و استقرار

```bash
npm run lint
npm run typecheck
npm test
npm run test:accounting
npm run test:legal
npm run test:security
npm run test:integrations # در حالی که برنامه تولیدی روی پورت 3003 اجراست
npm run test:warm         # سناریوی کامل مالک تا معامله و تسویه
npm run build
```

تست یکپارچه‌سازی بدون ارسال پیامک، مصرف AI یا ایجاد پرداخت واقعی، دسترسی فایل خصوصی، جلوگیری از دسترسی میان دو دفتر، خروجی CSV مستقل هر دفتر و محافظ API را روی سرور در حال اجرا بررسی می‌کند. برای نشانی دیگر، `INTEGRATION_BASE_URL` را تنظیم کنید.

راهنمای استقرار در [COOLIFY.md](./COOLIFY.md) و برنامه نگهداری و واکنش به رخداد در [OPERATIONS.md](./OPERATIONS.md) قرار دارد.
دروازه تست گرم و پذیرش مشتری در [RELEASE_CHECKLIST.md](./RELEASE_CHECKLIST.md) مستند شده است.
